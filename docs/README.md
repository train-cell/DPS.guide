# Τεκμηρίωση DPS.guide

Το [README στη ρίζα](../README.md) είναι ο τρέχων οδηγός εγκατάστασης, λειτουργίας και υποστηριζόμενων δυνατοτήτων. Ο κώδικας είναι η αυθεντική πηγή για την τρέχουσα υλοποίηση.

## Ιστορικά έγγραφα

- Το `PLAN.md` καταγράφει το αρχικό πλάνο του Οκτωβρίου 2026 και περιέχει παλιότερο scope, paths και αποφάσεις. Δεν είναι οδηγός εγκατάστασης ή προδιαγραφή της σημερινής εφαρμογής.
- Τα `orc*.txt` είναι ιστορικά prompts συντονισμού για παλιότερα streams/worktrees. Δεν είναι ενεργές οδηγίες για agents ή developers.
- Τα `requests/` και `requests/REPORT-*.md` είναι αρχικά αιτήματα και αναφορές ολοκλήρωσης. Η κατάστασή τους δεν περιγράφει το σημερινό repository.
- Το `eclass-protocol.md` περιέχει επαληθεύσεις από δοκιμές Thales της 2026-10-09. Είναι χρήσιμο ιστορικό, αλλά κάθε σημερινή συμπεριφορά πρέπει να επιβεβαιώνεται ξανά από τον connector και τον τρέχοντα οδηγό.
- Τα `../handoff.md` και `../HANDOFF_DPS_GUIDE_2026-10-11.md` είναι snapshots παλιότερης συνεδρίας. Αναφέρουν `main`, demo/mock flows και working-tree changes που δεν ισχύουν πια· δεν είναι ενεργές οδηγίες ή τρέχουσα κατάσταση.

Οι παλιές αναφορές σε production mocks, αρχεία μαθήματος ορατά στο iOS Files, μόνο-iOS διανομή ή παλιές παράλληλες ροές είναι ξεπερασμένες. Τα mocks/fixtures παραμένουν μόνο για offline tests.
