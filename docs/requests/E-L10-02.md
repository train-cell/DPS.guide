## 3. Per-adapter spec

Κοινά: `import { ok, apotyxia } from '@dps/core'` (helpers), τύποι από `@dps/core`. Όλοι οι adapters υλοποιούν τα interfaces του `packages/core/src/contracts/pyles.ts` **αυτολεξεί**:

```ts
export type KodikosSfalmatos =
  | 'AUTH_APOTYXIA' | 'SESSION_LIXI' | 'DIKTYO' | 'TIMEOUT' | 'RATE_LIMIT'
  | 'MI_EGKYRO_SXIMA' | 'DEN_VRETHIKE' | 'MI_YPOSTIRIZOMENO'
  | 'PROYPOLOGISMOS' | 'AKYROTHIKE' | 'AGNOSTO';

export interface Sfalma { kodikos: KodikosSfalmatos; minima: string; aitia?: unknown }
export type Apotelesma<T> = { ok: true; timi: T } | { ok: false; sfalma: Sfalma };
```

### 3.1 `CapacitorApothiki` — `ApothikiPyli` (filesystem)

Contract (verbatim `pyles.ts`):

```ts
export interface ApothikiPyli {
  diavase_keimeno(diadromi: string): Promise<Apotelesma<string>>;
  grapse_keimeno(diadromi: string, periexomeno: string): Promise<Apotelesma<void>>; // atomic
  diavase_dyadiko(diadromi: string): Promise<Apotelesma<Uint8Array>>;
  grapse_dyadiko(diadromi: string, dedomena: Uint8Array): Promise<Apotelesma<void>>; // atomic
  yparxei(diadromi: string): Promise<boolean>;
  lista(fakelos: string): Promise<Apotelesma<string[]>>;
  diagrafi(diadromi: string): Promise<Apotelesma<void>>;
}
```

Behavior (twin του `NodeFsApothiki`):
- Constructor `constructor(private readonly riza: string, zoi?: ZoiFilesystem)` όπου `riza` = λογική ρίζα μέσα στο `Directory.Documents` (π.χ. `'spoudes'`). Όλες οι διαδρομές περνούν από `karnikopoise_diadromi` (mirror) → `MI_EGKYRO_SXIMA` σε κενό/`..`/traversal· join με `riza` με `/`.
- `grapse_keimeno`/`grapse_dyadiko`: **atomic** = `writeFile` σε `<proorismos>.tmp-<uuid>` (id → ⚠️VERIFY `crypto.randomUUID` διαθέσιμο στο WebView· εναλλακτικά `Date.now()+random`), μετά `rename` στον τελικό. `deleteFile(tmp)` σε `finally` (catch-ignore). `mkdir(recursive:true)` πριν.
- `grapse_keimeno` → UTF-8· `grapse_dyadiko` → **base64** (⚠️VERIFY αν δέχεται `Uint8Array`/`Blob` απευθείας; αν όχι, `btoa`-encode το `Uint8Array`).
- `diavase_dyadiko` → decode base64 → `Uint8Array`. `diavase_keimeno` → string.
- Missing file → `DEN_VRETHIKE`. Directory-because-file (EISDIR ανάλογο) → `MI_EGKYRO_SXIMA`.
- `yparxei`: `stat` → `ok:true` μόνο για **αρχείο** (`FileInfo.type === 'file'` ⚠️VERIFY field), αλλιώς/σε σφάλμα `false`.
- `lista(fakelos)`: **αναδρομικό** walk (το `readdir` του plugin ΔΕΝ είναι recursive — `docs/PLAN.md` L10 «Κανονικοποίηση διαδρομών κατά §5.3»). Ανύπαρκτος φάκελος → **`ok([])`** (συμφωνία E-L10-01 #1, ταιριάζει με `MnimiApothiki` + `NodeFsApothiki`). Επιστρέφει σχετικές διαδρομές, sorted.
- `diagrafi`: επιτυχία → `ok(undefined)`· ανύπαρκτο → `DEN_VRETHIKE`.

Πλατφόρμα plugin calls (όλα ⚠️VERIFY):
- `import { Filesystem, Directory, Encoding } from '@capacitor/filesystem'`
- `Filesystem.writeFile({ path, data, directory: Directory.Documents, recursive: true, encoding? })`
- `Filesystem.readFile({ path, directory })` → `{ data }`
- `Filesystem.readdir({ path, directory })` → `{ files }` (⚠️VERIFY: `FileInfo[]` ή `string[]`)
- `Filesystem.stat({ path, directory })`, `Filesystem.mkdir({ path, directory, recursive })`
- `Filesystem.rename({ from, to, directory })` ⚠️VERIFY αν overwrite υπάρχοντος (iOS `moveItem` αποτυγχάνει αν ο προορισμός υπάρχει → fallback: `deleteFile(proorismos)` πριν το rename)
- `Filesystem.deleteFile({ path, directory })`, `Filesystem.getUri({ path, directory })` (διάγνωση)

### 3.2 `CapacitorKatevasmaPyli` — `KatevasmaPyli` (download)

Contract (verbatim):

```ts
export interface KatevasmaPyli {
  katevase(
    url: string,
    proorismos: string,
    kefalides: Record<string, string>,
    simatodotis?: AbortSignal
  ): Promise<Apotelesma<{ megethos: number }>>;
}
```

Behavior:
- `proorismos` = λογική διαδρομή (ίδιοι κανόνες §5.3 μέσω `karnikopoise_diadromi`). Καλεί `mkdir` του parent (recursive) πριν το download.
- Ο **ρητός** `Cookie` header ταξιδεύει μέσα στο `kefalides` — ο caller τον γεμίζει από το `CookieJar` (βλ. §3.3). Ο adapter ΔΕΝ παράγει cookies. Αυτό είναι το mitigation του PLAN §12 risk «Τα downloads στο iOS δεν στέλνουν cookies» (ρητό header Cookie).
- Επιτυχία → `ok({ megethos })` όπου `megethos` από `stat` μετά το download (`FileInfo.size` ⚠️VERIFY field).
- `simatodotis.aborted` πριν την έναρξη → `apotyxia('AKYROTHIKE', ...)`. Αν το plugin δεν υποστηρίζει cancel ⚠️VERIFY: μην εφεύρεις API — κατέγραψε ως ανοιχτό στο report και υλοποίησε best-effort `try/catch` (αν το `downloadFile` απορρίψει λόγω abort → `AKYROTHIKE`).
- Σφάλμα δικτύου → `DIKTYO`· σφάλμα I/O προορισμού → `AGNOSTO`. Μην διαρρέεις `url`/cookies στο `minima`.

Πλατφόρμα plugin calls (όλα ⚠️VERIFY):
- `import { FileTransfer } from '@capacitor/file-transfer'`
- `FileTransfer.downloadFile({ url, path, directory, headers, progress? })`
- `Filesystem.stat/getUri` από `@capacitor/filesystem` για `megethos`
- ⚠️VERIFY: ύπαρξη/όνομα του πακέτου και η υπογραφή (το legacy `FileTransfer` ήταν στο `@capacitor/filesystem`· το PLAN §6.3 ορίζει ξεχωριστό `@capacitor/file-transfer`).

### 3.3 `CapacitorHttpPyli` — `HttpPyli` (CapacitorHttp + CapacitorCookies)

Contract (verbatim):

```ts
export interface HttpAitima {
  methodos: 'GET' | 'POST' | 'HEAD';
  url: string;
  kefalides?: Record<string, string>;
  soma_forma?: Record<string, string>;
  soma_json?: unknown;
  akolouthise_anakateuthinseis: boolean;
  xronos_orio_ms: number;
  typos_apantisis: 'keimeno' | 'dyadiko';
  simatodotis?: AbortSignal;
}
export interface HttpApantisi {
  katastasi: number;
  kefalides: Record<string, string>;
  teliko_url: string;
  keimeno?: string;
  dyadiko?: Uint8Array;
}
export interface HttpPyli { aitima(a: HttpAitima): Promise<Apotelesma<HttpApantisi>> }
```

Behavior (twin του `NodeFetchHttpPyli`): **ίδιος** αλγόριθμος, με `CapacitorHttp` ως transport. Επαναχρησιμοποίησε τα mirrored pure modules:
- `anakateuthinsi(basika, ekdotis, zakari)` — ΧΕΙΡΟΚΙΝΗΤΟΣ βρόχος 30x, `MEGISTES_ANAKATEUTHINSEIS = 10`, 301/302/303 → GET (POST γίνεται GET, χάνει σώμα), 307/308 → διατηρεί μέθοδο+σώμα. Τα `Set-Cookie` **κάθε** ενδιάμεσης απόκρισης συλλέγονται ΠΡΙΝ την επόμενη (CAS ροή, `docs/PLAN.md` §8/§12).
- `CookieJar` (host-scoped, RFC 6265 path/domain match, secure-only-https) + `parse_set_cookies`. Το `Cookie` header χτίζεται από το jar ΚΑΙ γίνεται pass-through τυχόν `Cookie` του caller (join με `; `) — `dimiourgise_kefalides` mirror.
- `dimiourgia_somatos`: `soma_forma` → `application/x-www-form-urlencoded`, `soma_json` → `application/json`· και τα δύο μαζί → `MI_EGKYRO_SXIMA`· σε GET/HEAD ποτέ σώμα.
- `kefalides` επιστροφής → `Record<string,string>` (multi-values joined με `, `).

Σημείο αλλαγής transport = **μόνο** το `ekdotis_capacitor` (mirror του `ekdotis_fetch`):
- `CapacitorHttp.request({ url, method, headers, data, responseType, connectTimeout?, readTimeout? })` → `{ status, headers, data, url }` ⚠️VERIFY ονόματα πεδίων.
- `responseType`: `'text'` για `typos_apantisis:'keimeno'`, `'arraybuffer'` για `'dyadiko'` → map σε `Uint8Array` (⚠️VERIFY αν το `data` είναι ArrayBuffer/Blob/base64).
- **ΚΡΙΣΙΜΟ ⚠️VERIFY:** το native `CapacitorHttp` ακολουθεί ανακατευθύνσεις **αυτόματα** εσωτερικά και κατά πάσα πιθανότητα ΔΕΝ εκθέτει τα ενδιάμεσα `Set-Cookie`. Το Node twin βασίζεται σε `redirect:'manual'`. Πρέπει να επιβεβαιωθεί αν το `CapacitorHttp` επιτρέπει απενεργοποίηση auto-redirect. **Αν ΔΕΝ το επιτρέπει:** ο hand-rolled βρόχος δεν θα βλέπει τα ενδιάμεσα 30x → η shared contract suite (πολλαπλά hops CAS) θα αποτύχει. Τότε → **BLOCKED escalation**: απαιτείται native custom plugin (PLAN §12 «fallback login σε WebView … custom native plugin για κοινά cookies»). ΜΗΝ το κρύψεις με fallback που αλλάζει σιωπηλά σημασιολογία.
- `CapacitorCookies`: χρήση ως **συμπληρωματική** πηγή (cookies που έθεσε το WebView/native layer, π.χ. login), ΟΧΙ ως αντικαταστάτης του deterministic `CookieJar`. ⚠️VERIFY: `CapacitorCookies.getCookies({ url })` / `setCookie({ url, key, value })` υπογραφές (iOS-only; ύπαρξη στο `@capacitor/core`).
- Error mapping (mirror `anakateuthinsi`): timeout → `TIMEOUT`· abort → `AKYROTHIKE`· network → `DIKTYO`· άκυρο URL → `MI_EGKYRO_SXIMA`· >10 hops → `DIKTYO` με μήνυμα `Υπέρβαση μέγιστου αριθμού ανακατευθύνσεων (10)`. **Κανένα cookie/μυστικό σε `minima`/logs** (PLAN L11 «κανένα cookie/μυστικό σε logs»).

5. `@aparajita/capacitor-secure-storage`: export style + `configure()`/namespacing.
6. `crypto.randomUUID` διαθεσιμότητα στο WebView runtime για το temp id.
- Αν οποιοδήποτε ⚠️VERIFY αποκλίνει από το spec → ενημέρωσε §3 (σχόλιο docstring) ΚΑΙ κατέγραψε στο report· μη σιωπηλό workaround.
