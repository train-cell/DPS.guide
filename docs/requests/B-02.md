# Αιτήματα B-02 — Stream B (λειτουργικά, εκτός ownership)

Τίποτα από τα παρακάτω δεν το άλλαξα μόνος μου. Καθένα θα σπάσει/αφήσει ασυνέπειο
αν δεν αλλάξει ο owner ή ο integrator.

## 1. `stream/B` στο `ownership.json` (BLOCKING για το check)

Το `pnpm check:ownership --lane stream/B` **αποτυγχάνει** με
`Unknown lane or stream: stream/B` — το `ownership.json` έχει `W0, S1, L01..L16, stream/A, stream/C, stream/D, stream/E`
αλλά όχι `stream/B`.

Ζητάω προσθήκη: `"stream/B": ["packages/mock-eclass/**", "spikes/s1-thales/**", "fixtures/eclass/**", "scripts/scrub-fixtures.mjs", "docs/eclass-protocol.md", "docs/requests/B-*.md"]`.

Μέχρι τότε ο έλεγχος ownership γίνεται χειροκίνητα με `git status --porcelain`
(καθαρό — μόνο τα δικά μου paths).

## 2. `scripts/*.test.mjs` στο glob του S1

Το ownership του S1 είναι `scripts/scrub-fixtures.mjs` (ακριβές αρχείο). Το test του scrubber
χρειάζεται `scripts/scrub-fixtures.test.mjs` και **δεν** ταιριάζει σε κανένα glob μου.

Προσωρινά το έβαλα στο `spikes/s1-thales/tests/scrub-fixtures.test.mjs` (μέσα στα δικά μου globs).

Ζητάω: να προστεθεί `scripts/**/*.test.mjs` στο glob του S1, ώστε το test να ζει δίπλα στο script
(σήμερα τρέχει με `npx vitest run spikes/s1-thales` αντί για `npx vitest run scripts/`).

## 3. `pnpm install` για το νέο package (lockfile εκτός reach)

Το `packages/mock-eclass` δεν είχε `node_modules`, οπότε το `@dps/core` δεν είχε link
(το `packages/adapters-node` το έχει ως junction που δημιούργησε το pnpm).

Δεν τρίξα `pnpm install` (θα άγγιζε `pnpm-lock.yaml` → απαγορευμένο). Δημιούργησα χειροκίνητα
την ίδια δομή junctions στο `packages/mock-eclass/node_modules/` (`@dps/core`, `typescript`, `vitest`).
Είναι gitignored, **δεν** είναι commit, αλλά δεν είναι νόμιμο pnpm state.

**Ενέργεια owner:** `pnpm install` στο root. Αναμένεται να μην αλλάξει τίποτα στο `pnpm-lock.yaml`
(το `workspace:*` του `@dps/mock-eclass` είναι ήδη εκεί μέσω του workspace glob `packages/*`).

## 4. `eslint.config.mjs` λείπει → `npx eslint packages/mock-eclass` αποτυγχάνει

```
ESLint couldn't find an eslint.config.(js|mjs|cjs) file.
```

Το αρχείο είναι παράδοτο του W0 (§6.1) και είναι εκτός ownership μου.
Το ίδιο θα πέσει σε **κάθε** lane, όχι μόνο σε εμένα.

Το ίδιο ισχύει και με τα `no-console`: τα `spikes/*.mjs` και τα `scripts/*.mjs` τυπώνουν σε stdout
(σκόπιμα — είναι CLI probes που διαβάζει ο owner). Χρειάζεται εξαίρεση στη ρύθμιση
για `spikes/**` και `scripts/**`, αλλιώς το `pnpm lint` θα αποτυγχάνει εκεί.

## 5. `*.tsbuildinfo` δεν είναι στο `.gitignore`

Το `tsc --build` παράγει `packages/core/tsconfig.tsbuildinfo` και
`packages/mock-eclass/tsconfig.tsbuildinfo` ως **untracked**. Χωρίς ignore, κάθε agent
που τρέξει typecheck βγάζει θόρυβο στο `git status` (και κίνδυνος accidental add).

**Ενέργεια owner:** προσθήκη `*.tsbuildinfo` στο `.gitignore`.

## 6. `scripts/test-lock.mjs` δεν βρίσκει το `vitest` (παρατηρήση)

`pnpm test` τρέχει `node scripts/test-lock.mjs vitest run`. Το `spawn` γίνεται με `shell: false`,
άρα στα Windows το `vitest` (`.cmd`) δεν βρίσκεται → `spawn vitest ENOENT`.
Το ίδιο με `npx vitest run` (`spawn npx ENOENT`).

Δεν το άλλαξα (εκτός ownership). Επαλήθευσα με `npx vitest run` από root: **59 passed**.
Πιθανή διόρθωση: `shell: true` ή `process.execPath` + `node_modules/vitest/vitest.mjs`.

## 7. `tsconfig.json` root χωρίς reference στο `packages/mock-eclass`

Το root `tsconfig.json` έχει references σε core/extract/adapters-node/mobile· όχι στο `mock-eclass`.
Το `pnpm typecheck` (root `tsc --build`) δεν πιάνει το νέο package.
Το root `tsconfig.json` είναι εκτός ownership μου.

**Ενέργεια owner:** προσθήκη `{ "path": "./packages/mock-eclass" }` στο root `tsconfig.json`.
(Το ίδιο θα χρειαστεί για κάθε επόμενο package.)

## 8. `zod` ως direct dependency του `mock-eclass` (επιλογή, όχι ανάγκη)

Το `MathimaSchema` έρχεται έτοιμο από το `@dps/core`. Για το `KomvosArxeiou` **δεν** υπάρχει
schema στο frozen core, οπότε έγραψα χειροκίνητο validator (`elegxe_komvos_arxeiou`) για να
μην προσθέσω dependency που θα άλλαζε το lockfile.

Αν προτιμάτε ομοιόμορφη zod επικύρωση, χρειάζεται `"zod": "^4.6.5"` στο
`packages/mock-eclass/package.json` + `pnpm install` — **αλλαγή lockfile**, άρα owner.
