# fixtures/fonts — Noto Sans (OFL-1.1)

- Αρχείο: `NotoSans-Regular.ttf`
- Άδεια: SIL Open Font License 1.1 (`https://scripts.sil.org/OFL`)
- Πηγή: google/fonts repository, `ofl/notosans/NotoSans[wdth,wght].ttf`
  (variable font: 4515 glyphs, πλήρης κάλυψη ελληνικών/λατινικών)
- Χρήση: ενσωμάτωση στα συνθετικά PDF fixtures (L05). Οι standard 14
  γραμματοσειρές PDF δεν περιέχουν ελληνικούς χαρακτήρες, άρα η embedded
  γραμματοσειρά είναι υποχρεωτική για ελληνικά fixtures.

Προορισμός: fixtures/ αποθήκευση (gitignored αν δεν υπάρχει εξαίρεση).
Η άδεια OFL επιτρέπει αναδιανομή μαζί με το repo.
