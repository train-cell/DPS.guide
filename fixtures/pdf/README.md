# fixtures/pdf — Συνθετικά PDF (L05)

Τα αρχεία αυτά **δεν** δημιουργούνται με το χέρι: τα φτιάχνει το
`scripts/make-fixtures/pdf.mjs` (pdf-lib + @pdf-lib/fontkit + ενσωματωμένη
γραμματοσειρά **Noto Sans**). Οι standard γραμματοσειρές PDF δεν έχουν ελληνικά,
άρα η Noto Sans είναι υποχρεωτική.

Κανόνας §3.15 / κανόνας 2 του orcC: **ΚΑΝΕΝΑ πραγματικό υλικό μαθήματος**. Μόνο
συνθετικό κείμενο που γράφτηκε εδώ.

## Αναμενόμενα αρχεία (συμβόλαιο με τα tests)

| Αρχείο | Σελίδες | Περιεχόμενο |
|---|---|---|
| `notosans-tria-selides.pdf` | 3 | σελ.1 και σελ.3 με κείμενο, σελ.2 σχεδόν κενή |
| `notosans-keni-selida.pdf` | 2 | σελ.1 με κείμενο, σελ.2 σχεδόν κενή |

### Ακριβές κείμενο (UTF-8, NFC, με τόνους)

Τα tests κάνουν `expect(keimeno).toContain(...)`, άρα οι προτάσεις πρέπει να
εμφανίζονται **αυτούσιες** στο extracted κείμενο, με την ίδια γραφή:

- σελίδα 1 (πλήρης): `Οι δομές δεδομένων ταξινομούν στοιχεία κατά αύξουσα σειρά.`
- σελίδα 3 (πλήρης): `Η ανάζητηση δυαδικού δέντρου χρειάζεται αν ζητηθεί άμεση πρόσβαση.`

Η κενή σελίδα πρέπει να έχει < 5 λέξεις (ELAXISTES_LEKSEIS_SELIDAS), ώστε το test
της κενής σελίδας να έχει νόημα.

## Έκδοση

`pnpm fixtures:make` (script του root — βλ. `docs/requests/C1.md` αιτήματα 1 & 2):
τα αρχεία γράφονται στο `fixtures/pdf/`.
